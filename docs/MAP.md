# Map scope

The About page includes an implemented SVG country-level travel map. See [TRAVEL.md](TRAVEL.md) for the active content contract, visited-country tooltips, fullscreen dialog and accessibility behaviour.

The map intentionally does not use third-party tile services, geolocation or a city-level travel database. The Madeira visit appears under Portugal because the geometry uses national boundaries. Future city markers, travel photographs or more detailed geography would require a separate content and accessibility design.
